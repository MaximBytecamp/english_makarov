# Проверка текста перед публикацией

Прогоняется по каждой новой главе, практике и разделу до того, как страница
попадёт в оглавление. Порядок: сначала грепы, потом сплошная вычитка, потом
проверка утверждений. Пропускать второй шаг нельзя — он находит больше, чем
первый.

---

## 1. Каким должен быть текст

Взрослая лекция для студентов, которые тему ещё не знают. Связное объяснение
от абзаца к абзацу: термин вводится точно и сразу объясняется, без ссылок
вперёд и без пересказа того, что будет позже.

В трудных местах после точного термина — аналогия и конкретный пример,
и прямое объяснение, для чего это нужно. Каждую команду в блоке и каждое поле
на кадре разбирать в тексте, а не оставлять без пояснения.

Вводный абзац главы пишется как описание содержания («В этой главе разобрано…»),
а не как обращение к читателю. Абзац заканчивается фактом, а не выводом
сверх сказанного.

**Не добавлять:** сквозную историю, нарастающую «главную мысль», вопросы
к студенту («сначала ответьте сами»), придуманные названия блоков.

## 3. Сплошная вычитка: то, что грепы не ловят

Грепы находят известные строки. Всё остальное — только чтением. На практикуме
по `explain` из 16 найденных мест грепы дали 2.

Текст вытаскивается без разметки и читается подряд:

```bash
python3 - <<'PY'
import re, io, html
s = io.open('temy/NN-slug/index.html', encoding='utf-8').read()
s = s[s.index('<main'):s.index('</main>')]
s = re.sub(r'<(pre|style|script).*?</\1>', ' ', s, flags=re.S)
s = re.sub(r'<[^>]+>', '\n', s)
for line in s.split('\n'):
    t = html.unescape(line).strip()
    if len(t) > 25: print(t)
PY
```

Что искать глазами:

- **оценочный эпитет вместо указания**: «Главный экран разбора», «Главная
  плитка работы», «Вариант Б интереснее», «У варианта А плохи обе цифры»
  → назвать предмет: «Под заголовком Execution Stats идут восемь плиток»;
- **связка-усилитель «и есть то, что…»**: «Три верхних числа и есть то, что
  записывается в отчёт» → «Три верхних числа записываются в отчёт»;
- **пояснение-опровержение через двоеточие**: «Sort (0) — не ошибка: …»,
  «дело не в способе: …» — та же антитеза «X, а не Y», только замаскированная
  → «Sort (0) означает, что …»;
- **одушевление программы**: «план умеет показывать сам», «инструмент ничего
  не знает о вашей базе», «команда придирчива к оболочке»;
- **разговорное вместо точного**: «стенд просто работает», «вставлять можно
  куда угодно»;
- **висящее деепричастие** в подписях: «числа попадают в отчёт, не открывая
  файл» → «числа видны сразу, открывать файл не нужно»;
- **морализаторская подводка** перед разделом и «красивый» вывод в конце
  абзаца — обобщение сверх сказанного;
- **нагнетание про время и цену**: «стоит минуту», «за секунды», «час чужого
  времени».

Подписи к кадрам и ячейки таблиц проверять наравне с абзацами: слоп садится
туда чаще, потому что их читают по диагонали.

## 4. Снисходительный тон

Отдельная проверка. Конструкция, уже введённая в прошлых главах, не объясняется
«на пальцах» заново — это читается как недоверие к аудитории. Перед правкой
полезно посмотреть, каким языком о ней говорили раньше:

```bash
grep -rn 'курсор\|проекц\|фильтр' temy/0*/index.html | head -40
```

```bash
grep -rniE 'готовый ответ|это как|можно сказать|как бы|на самом деле всё просто' temy/*/index.html
```

## 5. Правдивость утверждений

Ни один из грепов выше этого не видит.

**Все модальные утверждения** — каждое проверяется контрпримером: сделать
наоборот и запустить.

```bash
grep -ohE '[^.<>]{0,55}(должн|нельзя|обязательн|всегда|никогда|единственн)[^.<>]{0,55}' temy/NN-slug/index.html
```

Если контрпример даёт тот же результат, на странице стоит не правило,
а соглашение — и писать его надо соглашением с причиной.

**Все упоминания одной конструкции подряд**: если два раздела определяют
одно и то же по-разному, один из них неточен.

```bash
python3 - <<'PY'
import re, io, html, sys
s = io.open('temy/NN-slug/index.html', encoding='utf-8').read()
body = s[s.index('<main'):s.index('</main>')]
for term in ['курсор', 'проекция', 'фильтр']:
    print('\n───── ' + term)
    for n, sec in enumerate(re.split(r'(?=<h2)', body)[1:], 1):
        t = html.unescape(re.sub(r'<[^>]+>', ' ', re.sub(r'<pre.*?</pre>', '', sec, flags=re.S)))
        for sent in re.split(r'(?<=[.!?])\s+', re.sub(r'\s+', ' ', t)):
            if term in sent and len(sent) > 30:
                print('  %3d  %s' % (n, sent.strip()[:108]))
PY
```

## 7. Что этот аудит вылавливает кроме стилистики

Каждый прогон, помимо формулировок, вскрывает содержательные дефекты —
их править отдельно и называть в отчёте:

- подсказка к заданию говорит про другой объект, чем само задание, или
  называет неверное число;
- ожидаемый вывод в тексте не совпадает с тем, что даёт прогон;
- два соседних раздела противоречат друг другу либо повторяют одну мысль;
- выдуманная точность в цифрах;
- термин введён без расшифровки;
- имя файла в шапке блока кода не совпадает с именем в тексте;
- один и тот же термин пишется по-разному в разных главах;
- кадр Compass снят на других данных, чем показывает пример рядом;
- кадры с ответом стоят внутри задания, которое студент должен решить сам
  (найдено в задаче 3 практикума: таблица с пропусками, а под ней снимки
  с заполненными числами).

## Шаблоны из справочника по Git (07.10.2026)

Найдены при правке справочника по Git и GitHub, встречаются во всех курсах.
Полный список с примерами — `~/git_github_makarov/shared/TEXT_REVIEW.md`, раздел 8.

```bash
grep -niE 'работаем на|вы пишете|а теперь добавьте|представим|простыми словами|отсюда точное|теперь видно|остаётся решить|именно|не просто|вовсе|и есть то|не случайно|обо что спотыка|это нормально|экономят|учебн(ый|ое|ая|ом|ого|ых)' "$A"
grep -nE '(нет|недоступен|сгорел|пропал|потеряли) — ' "$A"
```

- драматичное тире вместо условия: «Сервер недоступен — нельзя…» → «Когда сервер недоступен, …»;
- сценка и обращение к воображению во вводном абзаце: «Вы пишете курсовую…», «А теперь добавьте…»;
- несколько риторических вопросов подряд внутри абзаца → одно утверждение;
- утешение после факта: «— это нормально», «— обе стороны довольны»;
- связки «Отсюда точное определение», «Теперь видно», «Остаётся решить»;
- подводка обещает «два места», а перечислено три;
- второе «точное определение» термина в той же главе;
- блок команды или кадр без строки подводки сразу после другого блока;
- правило в строке «Что получилось» вместо результата;
- один результат показан кадром, таблицей и пересказом сразу — оставить один способ;
- слово «учебный» в тексте не используется.
