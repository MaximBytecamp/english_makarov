# Разговорный английский

Книга для поездок и переезда: ситуации от аэропорта до аренды квартиры, транскрипция и русская
подсказка к каждому слову, озвучка голосом, упражнения с перетаскиванием и повтор ошибок.

Автор — Макаров Максим Николаевич.

Открыть локально: `python3 -m http.server` в корне и перейти на http://localhost:8000.
План и правила разметки — в [PLAN.md](PLAN.md).
